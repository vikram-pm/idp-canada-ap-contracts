07 · AI approach

AI confidence is earned with evidence

1

Grounded

The model quotes the exact text it read. No quote, no value.

2

Consistent

A second, independent read must agree, compared by meaning.

3

Valid

Deterministic Canadian rules decide validity. The model only reads.

Architecture today: the AI reads each document directly (no RAG), and results are stored in n8n's own storage (no separate database). RAG is planned only for the NDA playbook.

Not verified → a personNDAs → always a person (pilot)AI outage → Manual with retry

08 · Model fit and cost

Right model for each job, about 2¢ per document

ModelRoleCost / doc (USD)Data in Canada
Gemini 2.5 Flash-LitePrototype: both reads$0.0009No (free tier)
Azure AI Document IntelligenceProduction read 1: invoices$0.015Yes (Canada region)
Azure OpenAI GPT-4.1-miniProduction read 2 + NDAs$0.0017Yes (regional deployment)

Why two different models

Independent models make different mistakes, so they rarely agree on the same wrong value.

How I would choose

Bake-off on ~200 real documents, ranked by false negatives first, then accuracy, latency and cost.
